연습 모드에서 쓸 수 있는 git 명령어

\- comit : 변경사항을 저장소에 기록하는 명령어

\- branch : 브랜치를 만들거나 관리하는 명령어

\- chechout : 브랜치를 전환하거나 특정 커밋으로 이동할 때 사용하는 명령어

\- cherry-pcick : 다른 브랜치의 특정 커밋 하나만 골라서 현재 브랜치에 가져오는 명령어

\- reset : head를 특정 커밋으로 되돌리는 명령어 

\-- sofrt : 커밋만 되돌리고 변경사항은 스테이징 영역을 남김

\-- mixed : 커밋값 되돌리고 변경사항은 스테이징 영역에 남김

\-- hard : 모든 걸 완전히 되돌림

\- revert : 커밋을 "취소하는 새 커밋" 을 만드는 명령어

\-rebase : 브랜치의 기반을 다른 커밋으로 옮기는 명령어

\-merge : 두 브랜치를 합치는 명령

메인

\- commit : 현재 작업 내용을 커밋(저장)하는 명령어. 새로운 커밋이 생성되고 현재 브랜치가 그 커밋을 가리키게 됨

\- branch : 새 브랜치를 만드는 명령어. 현재 위치(HEAD)에 새 브랜치 라벨을 붙임.

\- checkout : 다른 브랜치로 이동하는 명령어. HEAD가 그 브랜치를 가리키게 됨.

\- branch -f main c6 : 브랜치를 강제로 다른 커밋으로 옮기는 명령어. -f는 force(강제).

\- chekout HEAD~1 : 현재 위치(HEAD)의 부모 커밋으로 이동. ~1은 한 단계 위(부모)를 의미. : 

\- cherry-pick : 다른 브랜치의 특정 커밋을 골라서 현재 브랜치 위로 복사하는 명령어. 통째로 가져오는 게 아니라 원하는 커밋만 콕 집어서 가져옴.

원격

\- push origin main^:foo : 로컬 main의 부모를 원격 foo로 푸시

\- push origin foo:main : 로컬 foo를 원격 main으로 푸시

\- push origin :foo : 원격 foo 브랜치 **삭제**

\- fetch origin :bar : 로컬에 빈 brànch bar 생성

\- pull origin c3:foo : 원격 C3 → 로컬 foo로 받고 머지

\- branch -f main o/main : 로컬 main을 o/main 위치로 강제 이동
