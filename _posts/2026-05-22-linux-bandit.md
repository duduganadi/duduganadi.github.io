## level 1 - 2

**목표** : 리눅스에서 대시(-)로만 이루어진 특이한 파일 이름을 다루기.

**문제** : "-" 라는 이름의 파일이 홈 디렉토리에 있는데, 그 안에 다음 레벨 비밀번호가 있다.

**기본 개념**

`cat` = 파일 내용을 화면에 출력해줘! 라는 뜻의 명령어이다.

ex) hello.txt 파일이 보고 싶다면 `cat hello.txt` 라고 입력.

왜 `cat -` 라고 안하냐면? 리눅스에서 `-`는 특수한 의미가 있어서 `-`를 기호로 인식해버리기 때문에 `./`("지금 이 폴더 안에 있는" 이라는 뜻)를 앞에 붙여줘야 한다.

```bash
cat ./-
```

## level 2 - 3

**목표** : 리눅스에서 공백이 포함된 파일 이름을 다루기.

**문제** : "--spaces in this filename--" 이라는 이름의 파일이 홈 디렉토리에 있는데, 그 안에 다음 레벨 비밀번호가 있다.

**기본 개념**

1. 파일 이름에 띄어쓰기(공백)가 있으면 문제가 생긴다. 예를 들어 `cat spaces in this filename`을 리눅스는 spaces, in, this, filename 이렇게 4개로 인식한다.
2. 리눅스에서 `--`로 시작하는 건 옵션(설정값)으로 인식한다. (예: `cat --help` 하면 도움말이 나옴)

**해결 방법**

1-1. 따옴표로 감싸기

```bash
cat "spaces in this filename"
```

1-2. 백슬래시 사용 (공백 앞에 `\`를 붙이면 파일 이름의 일부임을 알려줄 수 있다.)

```bash
cat spaces\ in\ this\ filename
```

2-1. `--` 를 앞에 붙이기 (`--`는 "이 뒤에 오는 건 옵션이 아니라 파일 이름이야!"를 알려주는 신호이다.)

```bash
cat -- "--spaces in this filename--"
```

## level 3 - 4

**목표** : 리눅스에서 숨겨진 파일(Hidden File)을 찾고 다루는 방법을 배우기.

**문제** : inhere 라는 폴더 안에 숨김 파일이 있는데, 그 안에 비밀번호가 있다.

**기본 개념**

1. **숨김파일** : 리눅스에서 파일 이름이 `.`으로 시작하면 숨김파일이다. ex) `.숨김파일`
2. 숨김파일은 그냥 `ls` 하면 안 보인다.
3. 폴더 이동하는 방법 : `cd 폴더이름` = 그 폴더 안으로 들어가기 (cd = Change Directory의 약자)

**풀이 순서**

```bash
cd inhere        # inhere 폴더로 이동
ls -a            # 숨김 파일 포함해서 목록 보기 (-a = all의 약자)
cat ./.(파일이름) # 숨김 파일 읽기
```

## level 4 - 5

**목표** : 여러 개의 파일 중 사람이 읽을 수 있는 텍스트 파일이 무엇인지 찾아내기.

**문제** : inhere 폴더 안에 여러 파일이 있는데, 그 중 사람이 읽을 수 있는 파일 딱 하나에 비밀번호가 있다.

**기본 개념**

- **텍스트 파일** = 사람이 읽을 수 있는 파일
- **바이너리 파일** = 컴퓨터만 읽을 수 있는 파일
- `file` 명령어 : 파일이 어떤 종류인지 알려줌 (텍스트 파일이면 `ASCII text`라고 나옴)

**풀이 순서**

```bash
cd inhere      # inhere 폴더로 이동
ls             # 파일 목록 보기
file ./-*      # 모든 파일 종류 한번에 확인 (./-* = 지금 이 폴더 안에 있는 모든 파일)
cat ./-file??  # ASCII text 라고 나오는 파일을 cat 으로 읽기
```

## level 5 - 6

**목표** : 엄청나게 많은 디렉터리와 파일들 사이에서, 특정 조건(크기, 속성 등)을 만족하는 단 하나의 파일을 골라내는 방법 배우기.

**문제** : 다음 레벨로 가기 위한 비밀번호는 inhere 디렉터리 하위 어딘가에 있는 파일로 저장되어 있으며, 다음 세 가지 조건을 모두 만족한다.
1. 사람이 읽을 수 있는 형식
2. 정확히 1033바이트의 크기
3. 실행 파일이 아님

**기본 개념**

`find` 명령어 : 조건에 맞는 파일을 찾아주는 명령어

| 옵션 | 의미 |
|---|---|
| `-size 1033c` | 크기가 1033 바이트인 파일 |
| `! -executable` | 실행 불가능한 파일 |
| `-readable` | 사람이 읽을 수 있는 파일 |

`./`의 의미 : find 명령어는 "어디서부터 찾을지"를 먼저 말해줘야 한다. `find ./inhere`에서 `./inhere` = 지금 이 폴더 안에 있는 inhere 폴더에서 라는 뜻이다. 사실 이번에는 `./`가 없어도 가능하지만 `./inhere`라고 쓰는 게 더 정확하게 위치를 지정하기 때문에 습관적으로 붙이는 것이다.

```bash
find ./inhere -size 1033c ! -executable -readable
```

## level 6 - 7

**목표** : 서버 전체(/)를 뒤져서 소유자와 그룹, 크기 조건까지 만족하는 파일을 찾아내는 방법 배우기.

**문제** : 서버 어딘가에 파일이 있는데, 아래 조건을 모두 만족하는 파일에 비밀번호가 있다.
- bandit7 유저가 소유한 파일
- bandit6 그룹이 소유한 파일
- 크기가 33바이트

**기본 개념**

- `/` = 서버의 최상위 폴더
- 유저/그룹 : 리눅스는 파일마다 주인이 있다. 예를 들어 "이 파일은 bandit7 꺼야" 이런 식.
- `2>/dev/null` : "권한 없음" 오류를 안 보이게 숨겨주는 것

```bash
find / -user bandit7 -group bandit6 -size 33c 2>/dev/null
```

**기본 개념**

`grep` 명령어 : 파일 안에서 특정 단어가 있는 줄만 찾아주는 명령어

## level 8 - 9

**목표** : 비밀번호는 data.txt 파일 안에 저장되어 있으며, 오직 한 번만 나타나는 유일한 텍스트 줄이다. (다른 줄들은 여러 번 반복되어 나타난다.)

**문제** : data.txt 파일 안에서 딱 한 번만 나오는 줄에 비밀번호가 있다.

**기본 개념**

| 명령어 | 설명 |
|---|---|
| `sort` | 파일 내용을 알파벳 순서로 정렬, 같은 줄끼리 모아줌 |
| `uniq -u` | 딱 한 번만 나오는 줄만 보여줌 |
| 파이프 `\|` | 앞 명령어 결과를 뒤 명령어에게 넘김. ex) `sort data.txt \| uniq -u` |

```bash
sort data.txt | uniq -u
```

**문제** : data.txt 파일 안에 비밀번호가 있는데, `=` 문자가 여러 개 앞에 붙어있는 줄에 있다.

**기본 개념**

`strings` 명령어 : 파일 안에서 사람이 읽을 수 있는 텍스트만 뽑아줌

```bash
strings data.txt | grep ===
```

## level 10 - 11

**목표** : 데이터 변환 방식인 Base64 인코딩 다루기.

**문제** : data.txt 파일 안에 비밀번호가 base64로 인코딩되어 있다.

**기본 개념**

- **base64** : 데이터를 암호처럼 변환하는 방식. ex) `hello` → `aGVsbG8` 이런 식으로 바뀐다. 반대로 디코딩을 하면 원래 글자로 돌아온다.
- `base64 -d` 명령어 : base64로 인코딩된 걸 다시 원래대로 되돌려줌 (-d = decode의 약자)

```bash
base64 -d data.txt
```

## level 11 - 12

**목표** : ROT13 암호 해독 배우기. (글자를 특정 개수만큼 밀어서 치환하는 원리)

**문제** : data.txt 파일 안에 비밀번호가 있는데, 모든 알파벳이 13칸씩 밀려서 저장되어 있다.

**기본 개념**

- **ROT13** : 알파벳을 13칸씩 밀어서 바꾸는 방식. 알파벳이 26개이기 때문에 13칸 두 번 하면 원래대로 돌아온다.
- `tr` 명령어 : 특정 문자를 다른 문자로 바꿔주는 명령어

형식 : `tr '[원본 세트]' '[바꿀 세트]'`

ex) `tr 'A-Za-z' 'N-ZA-Mn-za-m'` = ROT13 디코딩. 여기서 `'A-Za-z'`는 모든 알파벳을 짧게 표현한 것.

```bash
cat data.txt | tr 'A-Za-z' 'N-ZA-Mn-za-m'
```

## level 12 - 13

**목표** : hexdump(16진수) 복원부터 시작해서 여러 겹으로 얽힌 압축 파일들을 하나씩 분석하고 해제하기.

**문제** : data.txt 파일은 hexdump 형식으로 저장된 파일인데, 여러 번 압축된 파일이다. /tmp 폴더 아래에 작업할 폴더를 만들어서 작업해라.

**기본 개념**

| 개념 | 설명 |
|---|---|
| `hexdump` | 파일 내용을 16진수(hex)로 변환해서 보여주는 것 |
| `xxd -r` | 16진수를 다시 원래 파일로 되돌림 |
| `gzip -d` | gzip(.gz) 압축 해제 |
| `bzip2 -d` | bzip2(.bz2) 압축 해제 |
| `tar xf` | tar(.tar) 압축 해제 |

**풀이**

홈 디렉터리에는 파일 생성 권한이 없기 때문에 `/tmp` 아래에 작업 폴더를 만들고 거기서 작업한다.

```bash
mktemp -d                     # 작업할 임시 폴더 만들기
cp data.txt /tmp/tmp.abcdef/  # 파일 복사
cd /tmp/tmp.abcdef/           # 폴더로 이동
xxd -r data.txt > data        # hexdump를 원래 바이너리 파일로 되돌리기
file data                     # 파일 종류 확인 후 해당 압축 해제 명령어 반복
```

## level 13 - 14

**목표** : SSH 개인 키를 활용해 다음 계정으로 직접 서버 내부에서 로그인(ssh) 하는 방법 배우기.

**문제** : 다음 레벨 비밀번호는 /etc/bandit_pass/bandit14 에 있는데, bandit14 유저만 읽을 수 있다. 이번엔 비밀번호 대신 SSH 개인키를 준다. 그 키로 다음 레벨에 접속하시오.

**기본 개념**

- **ssh** : 비밀번호 대신 열쇠 파일로 로그인하는 방식. 비밀번호 입력 없이 키 파일만 있으면 접속할 수 있다.
- **개인 키** : 내가 접속을 시도하는 내 컴퓨터에 보관
- **공개 키** : 내가 접속하려는 원격 서버의 `~/.ssh/authorized_keys` 파일 안에 저장

**풀이**

```bash
ls
<img width="354" height="128" alt="Image" src="https://github.com/user-attachments/assets/7680ade3-c7d1-4623-8885-81c98456b5da" />                                                                 # sshkey.private 파일이 있는 것을 확인
cat sshkey.private                                                   # 키 파일 내용 복사
exit                                                                 # 서버에서 나오기
nano sshkey.private                                                  # 내 Ubuntu에서 키 파일 만들기 (복사한 내용 붙여넣기)
chmod 600 sshkey.private                                             # 키 파일 권한 설정
ssh -i sshkey.private bandit14@bandit.labs.overthewire.org -p 2220   # 키로 bandit14 접속
cat /etc/bandit_pass/bandit14                                        # 비밀번호 확인
```

> 권한을 `chmod 600`으로 설정하지 않으면 ssh가 키 파일을 거부한다!

## level 14 - 15

**목표** : 서버의 특정 포트로 데이터를 보내고 받아오는 네트워크 통신의 기초 배우기.

**문제** : 현재 레벨의 비밀번호를 localhost의 30000번 포트에 제출하면 다음 레벨 비밀번호를 알려준다.

**기본 개념**

- **포트** : 컴퓨터에 있는 여러 개의 문. ex) 웹사이트는 80번, ssh는 22번 포트를 쓴다. 이번엔 30000번 문에 비밀번호를 보내는 것이다.
- `nc` 명령어 : 네트워크 연결을 해주는 명령어 (nc 주소 포트번호 = 그 주소의 그 포트에 연결해줘 라는 뜻)

```bash
nc localhost 30000
# 연결되면 현재 비밀번호 입력
```
